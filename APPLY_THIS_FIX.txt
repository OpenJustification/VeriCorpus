VeriCorpus 0.1.0 — PyInstaller CI Fix

CURRENT FAILURE
---------------
The latest run now reaches "Build graphical desktop bundle" and fails there on
both Windows Lite and Linux Lite.

This patch removes the custom spec file from the active CI build path.

Instead, both desktop workflows call:

    python scripts/build_desktop.py --flavor lite|full

The script invokes PyInstaller using explicit cross-platform options and prints
all build arguments directly into the GitHub Actions log.

It also verifies that dist/VeriCorpus is actually created.

FILES TO REPLACE/ADD
--------------------
.github/workflows/desktop-build.yml
.github/workflows/release.yml
scripts/build_desktop.py

HOW TO APPLY
------------
1. Extract this ZIP.
2. Copy its contents into your local VeriCorpus repository.
3. Replace existing workflow files when asked.
4. In GitHub Desktop confirm the three changed/new files.
5. Commit:
       Fix PyInstaller desktop build
6. Push origin.
7. GitHub -> Actions -> Desktop bundles -> Run workflow.

If PyInstaller still fails, the Actions log will now contain the direct
PyInstaller traceback/diagnostic output instead of hiding the issue behind the
custom spec file.
