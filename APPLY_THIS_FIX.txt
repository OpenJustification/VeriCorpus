VeriCorpus 0.1.0 — Windows GUI Wait Fix

ROOT CAUSE
----------
VeriCorpus.exe is built with PyInstaller --windowed, so Windows treats it as
a Win32 GUI application.

PowerShell can return control before a GUI executable exits when invoked
directly with:

    & .\dist\VeriCorpus\VeriCorpus.exe --self-test

That allows the workflow to inspect $LASTEXITCODE and desktop-selftest.json
before VeriCorpus has actually finished.

FIX
---
The Windows workflows now use:

    Start-Process -Wait -PassThru

This waits for the GUI executable to finish, captures the real process exit
code, and only then validates desktop-selftest.json.

FILES
-----
.github/workflows/desktop-build.yml
.github/workflows/release.yml

APPLY
-----
1. Extract this ZIP.
2. Copy its `.github` folder into your local VeriCorpus repository.
3. Replace both workflow files.
4. Commit in GitHub Desktop:
       Fix Windows GUI self-test wait
5. Push origin.
6. GitHub -> Actions -> Desktop bundles -> Run workflow.
