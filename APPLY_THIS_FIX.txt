VeriCorpus 0.1.0 — Models CI Fix

WHY THE DESKTOP BUILD FAILED
----------------------------
The GitHub Actions "Source smoke test" step runs:
  1. python -m vericorpus.desktop --self-test
  2. python scripts/release_check.py
  3. python scripts/license_check.py

The desktop self-test is okay.

The repository's .gitignore ignored the entire `models/` directory, so GitHub
Desktop did not upload these required release metadata files:

  models/benchmark-snapshot.json
  models/reference-open.json
  models/model-lock.example.json

release_check.py requires all three, and license_check.py reads
models/reference-open.json. Their absence makes the whole "Source smoke test"
step exit with code 1.

THIS PATCH
----------
- changes .gitignore so only small model metadata JSON files are tracked;
- continues to ignore large model weights/caches;
- adds the three required model metadata files.

HOW TO APPLY
------------
1. Extract this ZIP.
2. Copy `.gitignore` and the `models` folder into your local VeriCorpus repo.
3. Choose Replace/Merge when Windows asks.
4. Open GitHub Desktop.
5. Confirm you see these four changes:
     .gitignore
     models/benchmark-snapshot.json
     models/reference-open.json
     models/model-lock.example.json
6. Commit with:
     Fix tracked model metadata for CI
7. Push origin.
8. GitHub -> Actions -> Desktop bundles -> Run workflow.

Do NOT add downloaded model weights to Git. The updated .gitignore continues
to ignore *.safetensors, *.gguf, *.onnx, *.bin, *.pt, *.pth and cache/.
