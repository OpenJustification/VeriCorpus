# AI-assisted contribution policy

AI-assisted contributions are allowed. The human contributor remains fully responsible for the submitted
work, including correctness, tests, security, provenance, copyright, licensing, and compliance with the DCO.

## Requirements

- Review and understand all submitted code and documentation.
- Do not submit copyrighted or confidential material merely because a model produced it.
- Do not submit generated dependency code or copied license text unless its provenance and license are known.
- Add tests for behavior changes and preserve VeriCorpus evidence/abstention guarantees.
- Disclose substantial AI assistance in the pull-request description when it materially affected the change.
- Do not use automated agents to flood the project with unreviewed issues or pull requests.

Maintainers may request a human-authored explanation of any contribution before accepting it.
