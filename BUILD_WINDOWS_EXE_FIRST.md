# Build the three VeriCorpus 0.2.0 Windows EXEs

This document has been superseded by [BUILD_ALL_THREE_WINDOWS.md](BUILD_ALL_THREE_WINDOWS.md).

The new `.github/workflows/windows-exe.yml` builds **Lite, Standard, and Verified**
automatically after a GitHub Desktop push to `main` or `master`. Each package is
a separate `.zip` with `VeriCorpus.exe` and its supporting files.
